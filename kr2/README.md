## Содержимое материалов КР2

   - Файл: `task1_validation.js` — фрагмент `validateTaskDraft` с валидацией длины названия от 1 до 100 символов и нормализацией через `.trim()`.
   - Результат: обрезка краевых пробелов при успехе и объект ошибки при пустой строке.

2. **Задание 2 (ПР4 / localStorage):**
   - Файл: `task2_storage.js` — функции `saveTasks` и `loadTasks` для работы с ключом `tip-js-practice-04:demo` (версия 1).
   - Результат: сохранение задачи 20 «Изучить localStorage» (приоритет high) и восстановление после перезагрузки страницы.

3. **Задание 3 (ПР5 / Получение задач через API):**
   - Файл: `task3_api_get.js` — метод `getTasks` с передачей query-параметров `{ completed: false, priority: "high" }`.
   - Результат: выборка задач с сервера с id `[4, 13, 34]`, `meta.total = 3`.

4. **Задание 4 (ПР5 / Обработка HTTP-ошибок):**
   - Файл: `task4_api_error.js` — проверка `response.ok` в клиенте и вызов `getTaskById(999)` с перехватом в `try/catch`.
   - Результат: перехват ошибки с `kind: "http"`, `status: 404` без падения скрипта.

5. **Задание 5 (ПР6 / Изменение задачи через API):**
   - Файл: `task5_api_patch.js` — логика `toggleTask`, отправка `PATCH /api/tasks/:id` и последующий `GET /api/tasks?completed=false`.
   - Результат: задача 4 отмечена выполненной и исключена из фильтра невыполненных задач.

6. **Скриншоты и генерация:**
