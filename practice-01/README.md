## 4. Задание 1. Один файл — две среды выполнения
- При запуске в **Node.js**: строка `typeof document` возвращает `undefined`, так как в серверной среде отсутствует объектная модель документа (DOM).
- При запуске в **браузере**: `typeof document` возвращает `object`, так как браузер предоставляет глобальный объект документа для взаимодействия с HTML-страницей.

## 5. Задание 2. Исследование типов и преобразований

| Выражение | Ожидание | Факт | Тип | Объяснение |
|---|---|---|---|---|
| `"8" + 2` | `"82"` | `"82"` | `string` | Неявное приведение числа к строке и конкатенация |
| `"8" - 2` | `6` | `6` | `number` | Оператор `-` приводит строку к числу |
| `Number("8") + 2` | `10` | `10` | `number` | Явное преобразование строки в число |
| `"12" > "3"` | `false` | `false` | `boolean` | Лексикографическое (посимвольное) сравнение строк |
| `12 === "12"` | `false` | `false` | `boolean` | Строгое сравнение без приведения типов |
| `Number("")` | `0` | `0` | `number` | Пустая строка преобразуется в ноль |
| `Number("text")` | `NaN` | `NaN` | `number` | Нечисловая строка даёт значение `NaN` (тип `number`) |
| `Boolean("false")` | `true` | `true` | `boolean` | Любая непустая строка даёт `true` |
| `typeof null` | `"object"` | `"object"` | `string` | Историческая особенность реализации JavaScript |
| `typeof NaN` | `"number"` | `"number"` | `string` | Значение Not-a-Number является числовым типом |
